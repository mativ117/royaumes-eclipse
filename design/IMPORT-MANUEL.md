# Import manuel de secours du projet complet

1. Décompresser le ZIP.
2. Ouvrir le dépôt GitHub, puis Add file → Upload files.
3. Sur ordinateur, glisser le contenu du dossier décompressé : docs, src, design, historique, scripts, tests, vendor et les fichiers à la racine. Ne pas glisser uniquement le dossier parent et ne pas envoyer le ZIP lui-même.
4. Valider Commit changes.
5. Dans Settings → Pages, choisir main puis /docs et enregistrer.

Le jeu actuel est docs/index.html (version 0.4). Le lien historique docs/cathedrale-v03.html redirige vers lui. Les anciennes versions et leurs ZIP se trouvent dans historique. Le dossier porte ce nom pour éviter un conflit avec le fichier vide archive créé lors des premiers envois.

L’envoi de fichiers ajoute ou remplace ; il ne supprime pas automatiquement les anciens fichiers déjà à la racine du dépôt. Ils n’empêchent pas la publication depuis /docs. Aucun changement de visibilité ni reconnexion GitHub n’est nécessaire pour cet import manuel.
