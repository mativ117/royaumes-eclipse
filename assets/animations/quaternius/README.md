# Animations source Quaternius

Deux fichiers GLB d’origine, sans modification, issus des éditions **Standard gratuites** de Universal Animation Library et Universal Animation Library 2. Les variantes `_RM` contiennent le déplacement de racine et servent à mesurer puis adapter les mouvements de la Lame.

Le créateur les distribue sous **CC0 1.0 Universal**. Les fichiers `UAL1_License.txt` et `UAL2_License.txt` ainsi que les README d’origine sont conservés. Les éditions Pro et Source n’ont pas été téléchargées ; les annonces de 120+ animations du produit complet ne sont pas présentées comme une quantité entièrement gratuite.

Sources officielles :

- https://quaternius.itch.io/universal-animation-library
- https://quaternius.itch.io/universal-animation-library-2

Ces animations sont attribuées à Quaternius et décrites comme des animations réalisées par des animateurs. Leur présence ici ne constitue pas une preuve de capture de mouvement. Les meshes mannequin contenus dans ces fichiers restent des références techniques ; la géométrie originale de la Lame demeure celle du projet.

`PROVENANCE.json` conserve les empreintes des archives téléchargées et des GLB exacts, leurs membres d’origine, les identifiants de fichiers publics et les listes d’animations. Aucune URL de téléchargement temporaire signée n’est conservée.
