# KayKit Character Animations — Free 1.1

Sources officielles CC0 de Kay Lousberg, obtenues le 23 novembre 2026 depuis https://kaylousberg.itch.io/kaykit-character-animations. Seuls cinq ensembles GLB Rig_Medium utiles sont conservés. Les FBX, mannequins, ensembles de simulation/outils et la version SOURCE payante ne sont pas embarqués.

Ces fichiers ont été évalués pour une prochaine adaptation des pas orientés et des esquives. Ils ne sont pas intégrés aux animations de la livraison 1.5 : celle-ci utilise les mouvements Quaternius retargetés et les clips directionnels analytiques conservés. Le mannequin source n’est pas utilisé comme apparence de personnage. La licence d’origine et les empreintes accompagnent les fichiers ; le jeu ne les charge pas et ne contacte pas itch.io.
